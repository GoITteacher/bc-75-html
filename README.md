# Елементи форми

1. Приклади використання форм у веб-сайтах (авторизація, реєстрація, пошук, фільтри).

## Основи роботи з формами

- Структура HTML-форми: використання <form>, атрибути action, method.
- Чому зараз не використовується action для обробки даних.
- Підключення CSS для стилізації форм.

## Основні елементи форм (25 хвилин)

- Текстові поля: <input type="text">, <input type="email">, <input type="password">
- Кнопки та їхні типи: <button> (submit, button, reset)
- Робота з атрибутами: placeholder, value, required, disabled, readonly.
- Чекбокси та радіокнопки: <input type="checkbox">, <input type="radio">
- Випадаючі списки: <select> та <option>
